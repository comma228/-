
нахождение параметров ОС:
platform выводит тип ос и бит программной среды

version() выводит версию ос (для винды 10.0 означает базовый мажорный номер
#версии ядра системы. 28000 (конкретно в моем случае) это номер конкретной сборки ос)

release() -- #кодовое название ос

virtual_memory()._asdict -- возвращает в виде словаря:
1.total = общий объем памяти
2. available = реальный объем памяти, который можно выделить процессам
без перехода системы в подкачку (этот переход -- это когда ос переносит
часть данных из быстрой оперативной памяти на медленный жесткий диск)
3. percent = процент занятой памяти: (total - available) / total * 100
4. used = используемая память
5. free = полностью свободная память, которая еще не используется ничем

getcwd() -- возвращает каталог в котором сохранен файл
fsencode() -- кодирование строки в файлы для файловой системы.
#Она нужна в основном при написании кроссплатформенного кода,
#когда вам необходимо передать имя файла в низкоуровневые системные
#функции, работающие только с байтами

listdir() -- возвращает список, содержащий имена файлов и директорий в каталоге
#заданно путем path
